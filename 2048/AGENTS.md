# Як грати в 2048

Це місток до справжньої браузерної гри. Спочатку прочитай `README.md` у цій папці.

- Запуск із кореня AdsBot: `node 2048/bridge.js start --profile 137`.
- З іншої папки передай абсолютний шлях до `bridge.js`.
- Звичайний цикл: `state` → вибери 1–4 напрямки → `move LDDL` → оціни отримане поле.
- Напрямки: `L` вліво, `U` вгору, `R` вправо, `D` вниз. Нуль — порожня клітинка.
- Вибирай ходи самостійно. У містку немає алгоритму, який грає замість тебе.
- Пакет виконується без твоєї оцінки проміжних випадкових плиток. У складній позиції роби один хід.
- `status: "over"` / `over: true` означає кінець партії. Запиши результат; `new` починає наступну.
- Не починай нову партію автоматично після завершення, якщо користувач просив лише одну.
- `applied` — справді виконані ходи; `skipped` — напрямки без можливого зсуву.
- Для економії читай лише JSON містка. Не перечитуй HTML, усю CRM або код на кожному ході.
- За потреби: `inspect` — деталі гри; `screenshot` — зображення в `runtime/game.png`.
- `open` повертає до гри після закриття вікна, переходу на іншу сторінку або розриву підключення.
- `stop` від'єднує місток, залишає браузер відкритим.
- Не читай `.env` і не виводь адреси CDP, cookie або токени. Місток сам завантажує конфігурацію.
- Не змінюй стан гри через JavaScript, localStorage або запити до її API. Грай клавішами через місток.
