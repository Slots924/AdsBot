# Інструкції для роботи з проєктом AdsBot

## Опис проєкту

Це Node.js-проєкт для бота, який керує AdsPower через API.
Проєкт використовує JavaScript та ECMAScript-модулі.

## Основні правила

- Усі коментарі в коді писати українською мовою.
- Усі запити до AdsPower виконувати тільки через клас `AdsPower`.
- Не надсилати запити до AdsPower API безпосередньо з `index.js`, сервісів або інших частин проєкту.
- Логіку взаємодії з AdsPower API зберігати централізованою у класі `AdsPower`.
- Перед внесенням змін перевіряти наявну реалізацію та використовувати вже створені методи й сервіси.
- Не дублювати код, якщо потрібна логіка вже існує в проєкті.
- Не змінювати файли в папці `node_modules`.
- Не розкривати й не додавати до репозиторію секретні дані з `.env`, дані проксі або дані профілів.

## Файл для тестування

- Файл `test.js` використовується для ручної перевірки працездатності функцій.
- Нові або змінені функції можна перевіряти через `test.js`.
- Тестовий код у `test.js` має бути зрозумілим і не повинен без потреби змінювати реальні профілі AdsPower.

## Робота з класом AdsPower

- Публічні методи класу `AdsPower` мають використовувати внутрішній механізм виконання API-запитів.
- Черга запитів, затримки, обробка помилок і обмеження частоти запитів мають залишатися централізованими в класі `AdsPower`.
- Помилка одного запиту не повинна назавжди блокувати виконання наступних запитів.

## Перевірка змін

- Після змін запускати найменшу доречну перевірку.
- Для ручної перевірки функцій використовувати `test.js`.
- Не виконувати небезпечні операції з реальними профілями AdsPower без прямої вказівки користувача.
