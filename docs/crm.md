# CRM

Клас `classes/CRM.js` зберігає необов'язкові логін, пароль і сесію. Налаштування доступні у вкладці CRM в налаштуваннях програми. Сесію наразі можна ввести як довільний текст; її формат буде визначено після дослідження сайту.

Дані зберігаються локально у `data/local-secrets/crm.json`, зашифровані системним сховищем Electron. Для читання на тому самому комп'ютері потрібне доступне системне шифрування. Порожні поля дозволено зберігати та очищати.

Методи `getSettings()` і `saveSettings({ login, password, session })` повертають ці поля. Запити до CRM та авторизацію ще не реалізовано: адреса сайту, протокол і формат сесії поки невідомі. Майбутню взаємодію з API слід зосередити у класі CRM; секрети не записувати в логи.
