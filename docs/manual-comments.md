# Ручне коментування поста

У вкладці фанпейджів відкрийте «Закоментити пост» → «Вручну». Виберіть GEO, мову за потреби, номер креативу та групи AdsPower. Поле Offer URL використовує звичайну підстановку `<LINK>` у тексті креативу.

Після підтвердження праворуч видно пул: профілі з однозначним тегом статі без BAN і LOGIN_ERROR. Дублікати з різних груп прибираються. Кількість доступних чоловіків і жінок показується без попереджень про нестачу. Теги повторно перевіряються перед відкриттям.

«Відкрити» запускає профіль відповідної статі зі збереженими вкладками та перевіркою проксі через наявний метод `AdsBotGuiService.openAdsPowerProfile`. Текст копіюється в системний буфер через Electron. Після успішного відкриття й копіювання коментар вважається написаним. Повторне відкриття не додає ще одного успіху. Програма не переходить на пост і не публікує коментар автоматично.

- «Замінити» скасовує поточну спробу, закриває попередній профіль, якщо він відкритий, та відкриває наступний потрібної статі. Замінений профіль виключається з цього пулу.
- «Бан» також додає BAN через наявний сервіс тегів і фіксує бан у статистиці.
- Обидві дії повторно копіюють текст коментаря. Якщо пул закінчився, можна повернутися до рядка пізніше; успіх невдалої спроби не враховується.
- «Не написано» скасовує зарахування без заміни. Копіювання доступне окремою кнопкою.
- Натискання тексту розгортає повний коментар. Відповіді мають відступи й номер батьківського коментаря.

Учасники діалогів прив’язані через `profile_key`: різні учасники однієї статі отримують різні профілі. Якщо профіль уже має інші написані репліки, заміна недоступна. Бан такого учасника блокує продовження його діалогу; попередні успіхи зберігаються. Коментарі автора відображаються з неактивними кнопками і не входять у ручну статистику. Рядки з `should_write=false` також недоступні.

Стан сеансу зберігається локально в таблиці `manual_comment_sessions` бази статистики профілів після кожної дії. Незавершений сеанс відновлюється для того самого акаунта, фанпейджа й поста. Сеанси не містять проксі, cookies або токенів.

При закритті вікна, зокрема через Escape, зараховані рядки записуються в поле «Ручні коментарі» вкладки «Журнал» → «Статистика». Кожна подія має унікальний ключ, тому повторне завершення після збою не дублює лічильник. Ручні коментарі також входять у загальну кількість дій та порівняння забанених акаунтів. Після часткового збою завершення дозволено повторити закриття; інші дії заблоковані до завершення запису.

Перевірки: `node --test scripts/manual-commenting.test.js`, `npm --prefix frontend run test -- src/test/manual-comments.test.jsx`. Тести інтерфейсу та менеджера сеансів використовують виключно вигадані дані без підключення до AdsPower.
