# MyrahaMonster

У «Налаштування → Інтеграції» вкажіть API-ключ MyrahaMonster. Типова адреса API: `https://myrahamonster.xyz/api/v1`. Ключ шифрується через Electron safeStorage і зберігається у виключеній із Git папці `data/local-secrets/`; GUI отримує лише ознаку наявності ключа. Порожнє поле при збереженні залишає поточний ключ, прапорець видалення очищає його.

У вкладці «Сторінки» кожна картка має перемикач «Приховування коментарів». Він відображає бажаний глобальний стан `enabled`. За відсутності доступу або доступної підписки (`integrationReady=false`) перемикач заблокований. Вимкнення не відкриває раніше приховані коментарі.

Запити виконуються тільки через `classes/MyrahaMonster.js` з Bearer-авторизацією та таймаутом 30 секунд:

- `GET /pages?page=N` — повний список із пагінацією;
- `GET /pages/{pageId}` — перевірка стану конкретної фанки;
- `PATCH /pages/{pageId}/moderation` — тіло виключно `{ "enabled": true }` або `{ "enabled": false }`.

GEO, мова та креатив сервісу не імпортуються й не змінюються. Стан інтеграції відокремлений від локальних метаданих фанпейджів.

Різні фанки перемикаються паралельно без черги. API має ліміт 120 запитів/хв на ключ: `429` показується як помилка без автоматичного повтору. Список оновлюється при відкритті вкладки, ручному оновленні списку та збереженні налаштувань інтеграції; постійного опитування немає.

Якщо відповідь PATCH втрачена або некоректна, клієнт читає стан окремим GET без повторення PATCH. Якщо стан не вдалося встановити, потрібно натиснути кнопку перевірки біля перемикача. Помилка мережі не означає відсутність доступу. Відповіді попередніх налаштувань та застарілі списки не перезаписують новий стан.

Локальні перевірки без реального ключа:

```sh
node --test scripts/myraha-monster.test.js
npm --prefix frontend run test -- src/test/myraha-monster.test.jsx
npm --prefix frontend run build
```
