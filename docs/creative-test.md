# Тестування креативу за абзацами

У вкладці «Фанпейджі» виберіть сторінку та натисніть «Затестити креатив».
Виберіть бібліотечний креатив із GEO/мовою та Offer URL або ввімкніть власний текст.
Для власного тексту посилання визначається автоматично; якщо їх кілька різних — виберіть основне.
Потрібне одне спільне зображення для всіх оголошень.

Порожній рядок розділяє абзаци; переноси всередині абзацу зберігаються.
Режим «Наростаючим підсумком» створює варіанти 1, 1–2, …, 1–N.
Режим «Кожен окремо» створює варіанти 1, 2, …, N.
Основне посилання дописується в кінець кожного варіанта, якщо його там ще немає.
Blurry Font змінює лише текст поза URL.

Натисніть «Підготувати варіанти», перевірте тексти, виберіть рекламний акаунт і перейдіть до майстра кампанії.
Тексти фіксуються на етапі підготовки: запуск не перечитує бібліотеку й не генерує їх повторно.
До запуску можна повернутися до редагування без втрати форми.

Майстер використовує поточні шаблони, Pixel, UTM, бюджет і час рекламного акаунта.
Початкові статуси об’єктів беруться із загальних налаштувань і доступні для зміни.
Завжди створюється одна кампанія «Ліди», один адсет і N нових оголошень без публікації постів і коментарів.
Тестова копія шаблону використовує лише Facebook Feed, вимикає Advantage+ audience,
покращення креативу, Multi-advertiser ads, спільний бюджет адсетів та обмежені витрати на виключені плейсменти.
Збережений шаблон не змінюється. Обов’язкові DSA-перевірки залишаються.

Після запуску прогрес показує номер варіанта та посилання на кампанію в Ads Manager.
Створення кампанії не означає проходження модерації. Результати модерації перевіряйте в Ads Manager.
При частковій помилці отримані ID зберігаються у звичайному журналі кампаній;
кнопка очищення видаляє відомі створені об’єкти. Автоматичного повторного створення немає.

## Внутрішній контракт

`creatives:test-prepare` / `window.adsBot.prepareCreativeTest(input)` отримує
`geo`, `language`, `creativeName`, `siteUrl`, `sourceMode` (`library` / `manual`), `manualCreativeText`, `mode` (`cumulative` / `individual`),
`useCreativeFont` та необов’язковий `creativeFont`.
Повертає `{ creativeTest }` або `{ urls, selectionRequired: true }`, якщо потрібен вибір URL.

`creativeTest` містить `mode`, нормалізований `sourceText`, `siteUrl`, `creativeName`,
`variants: [{ first, last, label, text }]`.
Майстер передає його через наявні `campaigns:create-preflight` та `campaigns:create-start`
разом із `imagePath` і параметрами кампанії.
Backend повторно обчислює варіанти з зафіксованого тексту та відхиляє невідповідність.
Журнал зберігає тест і коректну кількість кроків; backend примусово встановлює один адсет.

## Перевірка

`node --test test/testCreativeTest.js` — підготовка, URL, шрифт, контракт, workflow, часткові помилки та журнал.
`npm --prefix frontend run test -- src/test/creative-test.test.jsx` — форма, інтеграція майстра й результат.
Обидва набори включені до `npm run test:campaign` та `npm run test:all`.
