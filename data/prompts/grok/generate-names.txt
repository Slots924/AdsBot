Ти генеруєш великий список реалістичних імен та прізвищ для Facebook-профілів під коментарі для вказаної країни.

ВАЖЛИВО: Поверни ТІЛЬКИ валідний JSON об'єкт без будь-яких пояснень, коментарів, markdown, backticks або додаткового тексту. Тільки чистий JSON.

ВХІД:
- geo: двобуквений код країни (US, DE, UK, UA тощо)
- gender: "male" або "female"
- count: кількість (зазвичай 200)

ПРАВИЛА ДЛЯ ІМЕН:
- Імена та прізвища мають звучати природно саме для цієї країни та мови.
- Уникай найпопулярніших імен і прізвищ для цього гео.
- СУВОРО: не використовуй перші топ-200 прізвищ за популярністю взагалі. Вибирай менш поширені, але все ще реалістичні прізвища, які реально зустрічаються в країні.
- Не використовуй імена знаменитостей, політиків, спортсменів, блогерів.
- Прізвища (lastName) повинні бути повністю унікальними в усьому списку — жодне прізвище не повторюється жодного разу.
- Імена (firstName) можуть повторюватися, але дуже рідко і рівномірно: одне і те саме ім'я може з'являтися не частіше ніж раз на 50 записів. Розподіляй їх по всьому списку. НЕ роби так, щоб кожен 2-й або 3-й чоловік мав ім'я "Артем", "John", "Michael" тощо. Імена мають бути різноманітними та сильно розкиданими.
- Для чоловічого gender — тільки чоловічі імена, для жіночого — тільки жіночі.
- Різноманітність: різні регіони країни, різні стилі (короткі, довгі, з різними закінченнями).

ФОРМАТ (повертай точно таку структуру):

  "names": [
    { "firstName": "Ім'я", "lastName": "Прізвище" },
    ...
  ]
}

Згенеруй рівно count записів. Нічого більше.

Додаткове правило (дуже важливо):
- Перевір у кінці: усі lastName унікальні.
- firstName повторюються максимум раз на 50 позицій і сильно розкидані.
