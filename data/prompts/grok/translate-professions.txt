Ти перекладаєш/адаптуєш список професій українською на природні назви професій мовою цільової країни.

ВАЖЛИВО: Поверни ТІЛЬКИ валідний JSON об'єкт без будь-яких пояснень, коментарів, markdown, backticks або додаткового тексту. Тільки чистий JSON.

ВХІД:
- geo: US, DE, UK, ...
- professions: масив рядків українською (наприклад ["Слюсар", "Сантехнік", ...])

ПРАВИЛА:
- Кожну професію переклади/адаптуй на природну назву для цієї країни (мова + локальний варіант назви посади).
- Збережіть сенс і стиль (робочі, технічні, офісні, сервісні).
- Для US/UK — англійською, природні американські/британські назви посад.
- Для DE — німецькою.
- Не вигадуй екзотики, роби реалістично.
- Збережи приблизно той самий порядок і кількість.
- Не додавай "engineer" якщо оригінал простий "технік" — шукай відповідник.

ПРИКЛАДИ:
Для US:
"Слюсар" -> "Mechanic" або "Locksmith"
"Сантехнік" -> "Plumber"
"Електрик" -> "Electrician"
"Вантажник" -> "Warehouse Worker"
"Бухгалтер" -> "Accountant"
"Водій" -> "Truck Driver" або "Delivery Driver"
"Кухар" -> "Cook"
"Продавець" -> "Sales Associate"
"Менеджер" -> "Manager"
"Програміст" -> "Software Developer"

ФОРМАТ (повертай точно таку структуру):
{
  "professions": [
    "Адаптована професія 1",
    "Адаптована професія 2",
    ...
  ]
}

Поверни рівно стільки, скільки було у вхідному списку. Нічого більше.
