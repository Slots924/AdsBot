# Мовна підтримка Facebook

- Якщо дія, модальне вікно, селектор або перевірка стану залежить від тексту чи мовного атрибута Facebook, підтримувати всі дев'ять мов: англійську (`en`), українську (`uk`), російську (`ru`), німецьку (`de`), французьку (`fr`), іспанську (`es`), гінді (`hi`), турецьку (`tr`) та індонезійську (`id`).
- Мовні варіанти зберігати централізовано у `facebook/i18n/`, в окремому файлі для кожної мови з однаковими ключами. Перед додаванням нового ключа перевіряти наявні й повторно використовувати їх.
- Отримувати варіанти через `facebook/i18n/index.js`; не дублювати масиви перекладів у actions, selectors, state чи modals.
- Початкові перевірки виконуються до перемикання на English: шукати варіанти всіх підтримуваних мов, не обмежувати пошук значенням `html.lang`.
- Порівнювати текст без урахування регістру після нормалізації пробілів. Для CSS-селекторів текстових атрибутів використовувати прапорець `i`; для не-ASCII тексту враховувати, що CSS `i` не гарантує порівняння без урахування регістру.
- Зберігати кілька формулювань одного напису як масив. Додавати підтверджені варіанти Facebook; неперевірені переклади не вважати підтвердженням роботи в живому браузері.
- Зміни мовного пошуку перевіряти локальними mock-тестами, включно з іншим регістром та відмовою на невідповідному тексті.
