# Мовні варіанти Facebook

Підтримувані мови: `en`, `uk`, `ru`, `de`, `fr`, `es`, `hi`, `tr`, `id`.
Кожна мова має окремий JS-файл з однаковими ключами та масивами формулювань.

- `login`: створення акаунта, вибір іншого профілю та вхід.
- `account`: назви кнопки акаунта/профілю для перевірки READY.
- `automatedBehavior`: попередження та кнопки закриття.
- `recovery`: захисний діалог, методи відновлення, кнопки, заголовки та помилки.

`getFacebookTexts("account.profileButton")` повертає варіанти всіх дев'яти мов без дублів.
Невідомий ключ або порожній масив у будь-якій мові викликає помилку, щоб пропущена мова не залишалася непоміченою.
Новий ключ потрібно додати в усі мовні файли.

Початкові перевірки використовують усі варіанти незалежно від `html.lang`, оскільки діалог може мати іншу мову.
Словник зберігає тексти; структуру DOM задають selectors, взаємодію виконують actions і state.
Перевірки за URL не потребують перекладів. Ads Manager не є головною сторінкою Facebook і не розпізнається як READY цим детектором.

Наявні варіанти входу, automated behavior та Dismiss перенесено з попередньої реалізації.
Додані переклади активного профілю та відновлення є варіантами для пошуку, а не записами з підтверджених живих сесій.
Mock-тести перевіряють їх підключення, регістр, пробіли та контекст відновлення; відповідність написам поточного інтерфейсу Facebook потрібно підтверджувати на реальних сторінках.
Коли з'являється нове формулювання, додавати його до відповідного масиву, зберігаючи попередні варіанти.
